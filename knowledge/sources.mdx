## Pregled

Svi povezani agenti čitaju sadržaj iz SharePoint biblioteka na sajtu `https://contoso.sharepoint.com/sites/DocsHub`. Knowledge source je jedini mehanizam dohvatanja — ne postoji „Get files“ ni listing alat.

## Biblioteke

### FIN

```
Document retrieval specialist for the FIN division of Contoso.
Searches and extracts content from contracts, annexes, parking agreements,
humanitarian organization contracts, VAS/BULK/PRM service agreements, rulebooks,
forms, and procedures. https://contoso.sharepoint.com/sites/DocsHub/Fin
```

Source: `share_info.txt` (FIN)

### DIGITAL

```
Search this source to read document content from the DIGITAL library.
Contains documentation for digital B2C projects: Identity Protect (Identity Protection, external
partner), Safe Home Net, Safe Net, and VR servis.
https://contoso.sharepoint.com/sites/DocsHub/Digital
```

Source: `share_info.txt` (DIGITAL)

### PORTAL

```
Search this source to read document content from the PORTAL library.
Contains benchmark analyses, purchase and payment matrices, SSO concept documents,
and functional requirements for the CX portal.
https://contoso.sharepoint.com/sites/DocsHub/Portal
```

Source: `share_info.txt` (PORTAL)

### KANALI

```
Search this source to read the full content of technical documents from the
Digitalni kanali division. ... Contains architecture documents, [redigovano],
deploy procedures, incident management processes, monitoring tools,
[redigovano], and roadmaps ...
https://contoso.sharepoint.com/sites/DocsHub/Kanali
```

Source: `share_info.txt` (KANALI)
