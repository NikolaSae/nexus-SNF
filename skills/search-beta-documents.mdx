## Namena

`search-beta-documents` dohvata relevantnu dokumentaciju iz knowledge source-a `BETA` i vraća činjeničan, strukturiran sadržaj pozivajućem agentu — ne ponaša se kao chatbot i ne daje finalne odgovore:

```
Retrieve relevant documentation from the BETA knowledge
source and return factual, structured content for the calling agent.
Do not act as a chatbot. Do not provide final user-facing answers.
```

Source: `search-beta-documents-skill.md` (Purpose)

| Projekat | Ključne reči |

| Orion | orion, identitet, digitalni identitet, dark web |
| Vega Home | vega home, kućni net, kućni internet, home internet protection |
| Vega | vega, mobilna zaštita, mobile protection, bezbedan internet |

Source: `search-beta-documents-skill.md` (Supported Projects)

<Warning>
Termin poput „vega“ sam po sebi može odgovarati na više projekata (Vega Home vs. Vega). Kada je namera nejasna, dohvataju se kandidati iz svih odgovarajućih projekata i označavaju po projektu.

Source: `search-beta-documents-skill.md` (Ambiguous keyword handling)
</Warning>

## Tipovi dokumenata

Service Scenario, User Instructions, Presentation, Contract, Business Decision — svaki sa svojim fokusom (opis servisa, uputstva, prezentacije, ugovorni uslovi, upravljačke odluke).

Source: `search-beta-documents-skill.md` (Supported Document Types)

## Prioritizacija po intentu

Prioriteti se **moraju poklapati** sa prioritetima pozivajućeg agenta (operativni / ugovorni / governance / opšti). Vraća se do 5 relevantnih dokumenata; ako ih je više, biraju se po prioritetu tipa, pa po datumu:

```
Return up to 5 relevant documents. If more than 5 qualify, select by:
Document type priority (per intent, see below)
Newest date within same priority level
```

Source: `search-beta-documents-skill.md` (Retrieval Strategy)

Ako nema relevantnih dokumenata, vraća se eksplicitan „no matching documents found“ — nikad se ne podmeću nepovezani dokumenti.

## Ekstrakcija i output

Izvlače se samo činjenice, u originalnom jeziku izvora, bez prevoda/parafraze; datumi, imena, nazivi proizvoda, obaveze, iznosi, koraci aktivacije i pravila naplate čuvaju se tačno. Za svaki dokument vraćaju se: naziv, tip, projekat, datum, razlog relevantnosti i izvučen sadržaj.

Source: `search-beta-documents-skill.md` (Extraction Rules; Output Requirements)
