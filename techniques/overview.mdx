## Gde se koriste

| Tehnika | Nosioci u sistemu |
|---|---|
| Multi-agent orkestracija | Orkestrator STEP 2, svi agenti |
| RAG / grounding | Svi domenski agenti i skillovi |
| Prompt injection defense | Orkestrator (AUTHORITY), svi skillovi (DATA vs. instructions) |
| Kontrola pristupa | Orkestrator (SESSION CONTEXT) |
| Validacija + retry | Orkestrator STEP 3/3.5, `validate-search-result` |
| Konstrukcija upita | `content-obrada-fin`, `sharepoint-intelligent-search` |
| Klasifikacija/ekstrakcija | `content-obrada`, svi domenski skillovi |
| Dizajn persone | Orkestrator (PERSONALITY) |
