## Session context

Identitet i pristup izvode se iz sesije i Entra ID profila:
```
SESSION CONTEXT User.Email is automatically available from the session. 
Derive UserLibrary from the user's department (department -> library mapping)
```
Source: `nexusbot_orchestrator_system_ins.txt` (SESSION CONTEXT)

Korisnik se oslovljava imenom iz profila sesije; nema memorije između sesija. Detalji rezolucije: [Rutiranje i kontrola pristupa](/orchestrator/routing-and-access).

## Sensitivity labels (Purview)

Skillovi surfaceuju Microsoft Purview sensitivity labele kada su prisutne:
```
If a Microsoft Purview sensitivity label is present on a document, 
include it with the extracted data (e.g., [Confidential]) — never suppress it.
```
Source: `content-obrada-fin-skill.md` (Step 4); `sharepoint-intelligent-search-dig-kan-agent-skill.md` (Step 5)

Više: [Purview sensitivity labels](https://learn.microsoft.com/en-us/purview/sensitivity-labels).
