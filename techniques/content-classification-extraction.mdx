## Šta je

Umesto da model „prepriča" dokument, ovaj obrazac ga prvo svrstava u tip (ugovor, procedura, lista servera...) pa po tipu izvlači tačno određena polja — doslovno, bez normalizacije. Time odgovor ostaje veran izvoru i proverljiv.

## Kako NexusBot to radi

### Klasifikacija po tipu

Svaki skill ima tabelu tipova sadržaja sa signalima. Primer (Digitalni kanali):
```
| server_list | [redigovano] | ALL rows: [redigovano] | | access_list | [redigovano] | ALL entries: [redigovano] | | ownership | 
KL, poslovni vlasnik ... | business owner, technical owner, 
doc title/version | | procedure | korak, Step, deploy | 
ALL numbered steps, in order | | architecture| server, baza, tehnologija | 
ALL components, technologies, connections |
```
Source: `sharepoint-intelligent-search-dig-kan-agent-skill.md` (Step 4)

### Verbatim, nikad apstraktno
```
Never describe what a document contains in the abstract. 
Never use phrases like "Contains:", "The document covers:", "Defines:". 
Always extract actual data — real steps, real rules, real dates, 
real names, real values, carried forward verbatim ...
```
Source: `sharepoint-intelligent-search-dig-kan-agent-skill.md` (Step 4)

Isti princip je u orkestratorovom skillu, sa zabranom srpskih fraza `"Sadržaj:"`, `"Dokument sadrži"`, `"Obuhvata:"`, `"Definiše:"`:
```
Copy names, emails, phones, contract numbers, dates, amounts VERBATIM. 
Never normalize, never invent.
```
Source: `content-obrada-nexus-skill.md` (Step 3)

### Osetljivi podaci i labele

Imena, email-ovi, telefoni, IP-jevi i hostname-ovi kopiraju se doslovno; nejasna vrednost se označava kao nepouzdano pročitana, nikad se ne pogađa placeholder-om (npr. „111 222"). Purview sensitivity labele se surfaceuju, nikad ne potiskuju.

Source: `sharepoint-intelligent-search-dig-kan-agent-skill.md` (Step 4); `content-obrada-fin-skill.md` (Step 4)

## Zašto je bitno

Klasifikacija određuje *šta* izvući, verbatim pravila garantuju *tačnost*, a zabrana apstraktnih opisa sprečava „glatke" ali neproverljive sažetke. To je poslednja karika grounding lanca (vidi [RAG / grounding](/techniques/rag-grounding)).
