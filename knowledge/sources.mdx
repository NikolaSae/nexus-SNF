## Pregled

Svi povezani agenti čitaju sadržaj iz SharePoint biblioteka na sajtu `https://contoso.sharepoint.com/sites/DocsHub`. Knowledge source je jedini mehanizam dohvatanja — ne postoji „Get files“ ni listing alat.

## Biblioteke

### ALFA

```
Document retrieval specialist for the ALFA division of Contoso.
Searches and extracts content from contracts, annexes, parking agreements,
humanitarian organization contracts, VAS/BULK/PRM service agreements, rulebooks,
forms, and procedures. https://contoso.sharepoint.com/sites/DocsHub/Alfa
```

Source: `share_info.txt` (ALFA)

### BETA

```
Search this source to read document content from the BETA library.
Contains documentation for digital B2C projects: Orion (external
partner), Vega Home, Vega, and VR servis.
https://contoso.sharepoint.com/sites/DocsHub/Beta
```

Source: `share_info.txt` (BETA)

### DELTA

```
Search this source to read document content from the DELTA library.
Contains benchmark analyses, purchase and payment matrices, SSO concept documents,
and functional requirements for the Delta portal.
https://contoso.sharepoint.com/sites/DocsHub/Delta
```

Source: `share_info.txt` (DELTA)

### EPSILON

```
Search this source to read the full content of technical documents from the
Epsilon division. ... Contains architecture documents, [redigovano],
deploy procedures, incident management processes, monitoring tools,
[redigovano], and roadmaps ...
https://contoso.sharepoint.com/sites/DocsHub/Epsilon
```

Source: `share_info.txt` (EPSILON)
