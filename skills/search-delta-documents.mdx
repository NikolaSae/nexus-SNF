## Namena

`search-delta-documents` dohvata relevantnu dokumentaciju iz Delta knowledge source-a i vraća činjeničan sadržaj pozivajućem agentu — zadužen je za retrieval i ekstrakciju, ne za odgovaranje korisniku:
```
Retrieve relevant documentation from the Delta knowledge sources 
and return factual content for the calling agent. This skill is 
responsible for retrieval and document extraction. Do not act as a chatbot.
```
Source: `search-delta-documents-skill.md` (Purpose)

## Domeni

Benchmark analize, Matrice kupovine i plaćanja, SSO koncepti, Funkcionalni zahtevi — svaki sa tipičnim temama (npr. za funkcionalne zahteve: click2call, deeplinking, consent management, Bloomberg/Deezer integracije, payment cards, 5G tarife).

Source: `search-delta-documents-skill.md` (Supported Domains)

## INDEX pravila

INDEX dokumenti su autoritativni agregirani izvori i uvek imaju prioritet:
```
Index documents are authoritative aggregated sources. 
Always prioritize index documents when available. Important examples:

_BENCHMARK_INDEX
_MATRICE_INDEX
_SSO_INDEX
```
Source: `search-delta-documents-skill.md` (INDEX DOCUMENT RULES)

Originalni `.pptx`/`.xlsx` fajlovi nisu pouzdano čitljivi; ako pretraga vrati samo fragmente (HTML tagovi, polomljene tabele), sadržaj se ne koristi — dokument se označava kao nečitljiv, vraćaju se samo naziv i link.

## Retrieval strategija

Za funkcionalne zahteve upit se drži uskim — samo naziv funkcije, bez generičkih reči:
```
For functional requirements topics, keep the search query narrow — use 
the specific feature name only (e.g. "click2call", "consent banner", "5G tarife"), 
without generic words like "zahtev" or "portal". Generic terms pull 
irrelevant documents.
```
Source: `search-delta-documents-skill.md` (RETRIEVAL STRATEGY)

Vraća se do 5 relevantnih dokumenata; prednost imaju tačna poklapanja, najnovije i odobrene/finalne verzije.

## Ekstrakcija po tipu i output

Skill čuva poslovna pravila, uslove podobnosti/plaćanja, zahteve, kriterijume prihvatanja, pravila autentikacije i integracije; imena, email-ove, telefone, IP adrese, hostname-ove i URL-ove kopira VERBATIM. Za matrice čuva sva pravila i izuzetke; za SSO čuva redosled toka; za benchmark iznosi samo dokumentovane zaključke.

Za svaki dokument vraća: tačan naziv (nikad izmenjen), pun SharePoint link, tip, verziju, datum, razlog relevantnosti i izvučen sadržaj.

Source: `search-delta-documents-skill.md` (EXTRACTION RULES; OUTPUT REQUIREMENTS)
